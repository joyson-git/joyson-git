<summary>⚙️ How to enable the real 3D contribution graph (one-time setup)</summary>

<br/>

The badges above (stats, trophies, streak) are live and need no setup. The **3D contribution graph** is different — it's a GIF/SVG that a GitHub Action regenerates daily, so it needs to be wired up once in your `joyson-git/joyson-git` repo.

1. In your profile repo, create the file `.github/workflows/3d-contrib.yml` with:

```yaml
name: 3D Contribution Graph

on:
  schedule:
    - cron: "0 0 * * *"   # runs daily at midnight UTC
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: yoshi389111/github-profile-3d-contrib@0.7.1
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        with:
          username: joyson-git
      - name: Commit output
        run: |
          git config user.name github-actions
          git config user.email github-actions@github.com
          git add -A
          git commit -m "Update 3D contribution graph" || echo "No changes"
          git push
```

2. Commit and push this workflow file, then trigger it once manually from the **Actions** tab (`Run workflow`).
3. It will generate SVGs under a `profile-3d-contrib/` folder — the README above already points to a common output path, but check the action's output filename and adjust the `<img src="...">` path in `README.md` to match exactly.
4. From then on, it auto-updates daily.

If you'd rather have a genuinely **animated** (not just isometric-styled) graph, swap the action above for [`Platane/snk`](https://github.com/Platane/snk), which produces a snake that visibly eats its way across your contribution grid as a moving GIF — closer to what people usually mean by "animation" on a profile. Say the word and I'll write that workflow instead.

</details>
